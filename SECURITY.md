# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in **Grovia**, please report it responsibly rather than opening a public issue:

1. Open a private vulnerability report via GitHub Security Advisories (`Security -> Advisories -> Report a vulnerability`), or contact the maintainer directly.
2. Include steps to reproduce, affected routes/components, and potential impact.
3. Allow reasonable time for remediation and coordinated disclosure before sharing details publicly.

We appreciate your efforts to keep Grovia and its contributors safe.
